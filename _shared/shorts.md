# Vertical lessons

Use 'python anim.py new my-short --format tall', optionally '--style line'. Teach one outcome. Put a useful picture in the first frame, keep text inside g.safe and hold diagrams long enough to read. A reset can help a loop when it serves the explanation.

Plan and review narration before cues. Captions reflect approved audio. Use _shared/mix.md for optional wipes. Edit the thumbnail starter, then run 'python anim.py thumbnail my-short' and inspect it at phone size.

To cut from a long project: 'new my-short --from my-long --start 0:20 --end 0:40'. Review the copied long script and make the short self-contained. Optional 'tighten' changes audio and retranscribes; review the revised take and timing.
