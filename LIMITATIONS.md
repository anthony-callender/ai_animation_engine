# Scope and limits

A clean learner starter derived from the production workflow. Offline validation covers the named synthetic exercise and recorded test environment. It does not validate every drawing primitive, every OS, or creative quality for unseen lessons. Mac/Linux use is unverified.

TTS, voice cloning, provider/model availability, paid requests, Whisper/model downloads, external/command capture and publishing were not exercised. Importing a recording does not need TTS.

Fonts are local. Python packages, FFmpeg, browser and optional speech model weights install separately with their own terms. Offline use begins after those dependencies are installed.

The source has no overall software license file. This handoff preserves notices and includes third-party licenses; it does not grant new redistribution/resale rights to the workspace code. Member access/reuse remains subject to the owner's terms.

References contain generic API snippets. The runnable worked example is labelled silent. App-view helpers are authored drawings, not proof of app actions. Capture redaction is best-effort.

No .env, owner voice ID, private projects/transcripts/voice samples, browser state, history, archives or publishing automation is included.
