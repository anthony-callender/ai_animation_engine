# Workflow

1. Voice: plan, script, record/import or optional TTS. Review the complete take.
2. Transcript: words.json and transcript.md. Check against audio.
3. Cues: authored cues.md compiled to cues.json/cues.js. Read the storyboard.
4. Scene: scene.js and assets. Review stills and watch the preview.
5. Export: MP4, thumbnail and source notes. Watch the exported file.

'python anim.py status' reports file presence, not approval. Keep decisions in each project's REVIEW.md.
