```
Publishing a Sunday sermon used to take a volunteer thirteen manual steps.

I built a Python workflow that turns a recorded church service into a WordPress draft. It runs when an operator starts it, and nothing goes live on its own.

The worker finds the sermon using liturgical cues, prepares the audio, and attaches the approved title, preacher and scripture. Here's how a run flows, step by step.

The result is a draft in WordPress. Where AI notes are turned on, they're checked for unsupported claims, and anything questionable is flagged for review. An editor checks the draft and publishes it as a sermon page like this one, where visitors can listen to the sermon, watch the full service, and read the scripture.

Running the same video again doesn't create a second post. I added duplicate checks on both sides.

That's how I approach automation: remove the repetitive steps, keep the safeguards, and leave people in control. Need a reliable AI automation or integration? Let's talk.
```
