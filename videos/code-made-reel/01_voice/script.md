# Narration (LinkedIn #17: "How I make my videos"), v2 2026-11-19: augmented, not automated; each stage. No talking head.
```
Every video on my feed was made with AI. Just not the way you'd think.

No Midjourney. No stock footage. No AI-generated faces.

And it isn't automated. It's augmented. I stay in the loop at every stage.

Here's how it works.

One. The idea. I record voice notes, and the best ideas come from real conversations, like the comments on my posts.

Two. The script. I write it in my own words, and AI helps me tighten it. Then my AI voice clone reads it.

Three. The timing. Speech-to-text stamps every word with the exact moment it's said.

Four. The storyboard. AI drafts every scene and pins it to a word. This card appears on this word. I review the board before anything gets built.

Five. The code. AI writes the code for each scene, and the code draws every frame, thirty times a second.

Six. The review. I check the frames, ask for changes, and nothing gets posted until I approve it.

Why build it this way? It's precise. A number on screen is the real number. It's predictable. Render it again, and you get the same video. And it still sounds like me, because I'm in the loop.

This video was made the same way.
```
