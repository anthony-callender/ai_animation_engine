# 03 — Storyboard
Read the checked transcript, brief and drawing references. Write cues.md with a heading such as:
## intro "a phrase from transcript"
Show the input.
## intro.change "another exact phrase"
Highlight the change.

Or use @0:04 for an explicit time, useful in silent work. Parent IDs are sections; dotted IDs are beats. Aim for useful changes every 3–8 seconds, adjusted for reading time.

Run 'python anim.py cues my-lesson'. It reads words.json and generates cues.json/cues.js. Do not edit those generated files. Parents stay active through sub-cues. Label captures, redraws and illustrations. Person reviews storyboard before scene work.
